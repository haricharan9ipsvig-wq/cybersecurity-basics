# Cybersecurity Basics 🔐

## About This Project
This repository documents my journey into cybersecurity, focusing on online safety, phishing awareness, and secure coding basics.

## What I Am Learning
- Recognizing phishing emails and suspicious links
- Using strong passwords and multi-factor authentication
- Protecting personal information online
- Keeping API keys and credentials out of source code
- Understanding basic input validation

## Phishing Safety Checklist
1. Verify the sender before trusting a message.
2. Be cautious of urgent requests for passwords or OTPs.
3. Visit official websites directly instead of clicking suspicious links.
4. Never share passwords or OTPs.
5. Report suspicious messages to the appropriate team.

## Secure Repository Checklist
- Never commit real passwords, API keys, or private information.
- Store secrets in environment variables or a secrets manager.
- Review changes before committing code.
- Revoke and rotate any exposed credentials immediately.
